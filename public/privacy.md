# Privacy Policy

**Agent Common** | Version 1.0 | Last updated: September 1, 2026

## Overview

Agent Common is a framework-agnostic specification repository for defining and orchestrating agents. This privacy policy explains how we handle information when you interact with the Agent Common project.

## Information We Collect

### Repository Data
- **GitHub interactions**: We may receive information about your GitHub activity (stars, forks, issues, pull requests) through public GitHub APIs.
- **Plugin usage analytics**: If you use the Agent Common plugin through ChatGPT or other Codex-compatible platforms, the hosting platform (OpenAI, etc.) collects usage data under their privacy policies.

### No Direct Collection
Agent Common does not directly collect personal information. The specification and codebase are public and do not require account registration or data submission.

## How We Use Information

We use collected information to:
- Understand how the project is being used
- Improve documentation and tooling based on community feedback
- Monitor project health and adoption

## Data Retention

GitHub data is retained according to GitHub's retention policies. No additional data is stored by the Agent Common project.

## Third-Party Services

- **GitHub**: All code and discussions are hosted on GitHub. Review [GitHub's Privacy Policy](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
- **OpenAI / Plugin Platforms**: When used as a plugin, your interactions are governed by the hosting platform's privacy policy.

## Your Rights

You have the right to:
- Access information about how your data is used
- Request clarification on data practices
- File issues or contact us with privacy concerns

## Contact

For privacy questions or concerns, please open an issue on the [GitHub repository](https://github.com/Kaancodm/Agent-common/issues) or contact the maintainers.

## Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected here with an updated "last updated" date.
