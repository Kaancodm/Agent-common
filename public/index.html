Why Agent Common?

Framework-Agnostic

Define agents once, deploy anywhere. No vendor lock-in, no runtime dependencies.

Security-First

Built-in approval gates, permission boundaries, and handoff verification.

Specification-Based

Pure Markdown + JSON + YAML. No build process, no runtime overhead.

Composable Skills

Reusable skill templates for common tasks. Mix and match in your workflows.

Observable Workflows

Traceable handoffs, clear decision points, explicit completion criteria.

Plugin-Ready

Publish to ChatGPT, LLM platforms, and AI marketplaces with built-in manifest.
